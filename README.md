# TuneCrate - Music Player Web Application

A modern, responsive music player web application built with React and Vite that features dynamic UI elements and a personalized music experience.

## Features

- **Personalized Experience**: View recently played tracks, favorites, and top tracks
- **Dynamic Color UI**: Background changes based on album artwork
- **Music Controls**: Play, pause, next, previous, and volume controls
- **Search Functionality**: Find tracks by title or artist
- **Responsive Design**: Works on both desktop and mobile devices
- **Dark Mode**: Comfortable viewing experience
- **Local Storage**: Remembers your favorites and play history

## Technologies Used

- React.js
- Vite (for fast development and optimized builds)
- React Bootstrap
- SCSS for styling
- Color Thief for dynamic color extraction
- React Icons

## Installation

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Setup Instructions

1. **Clone the repository**

```bash
git clone https://github.com/Tanmay2001Choudhary/TuneCrate
cd TuneCrate
```

2. **Install dependencies**

```bash
npm install
```
or
```bash
yarn install
```

3. **Start the development server**

```bash
npm run dev
```
or
```bash
yarn dev
```

4. **Open the application**

Open your browser and navigate to `http://localhost:5173` (Vite's default port)
